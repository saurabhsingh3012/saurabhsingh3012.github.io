How squashed is your music?

Drop in an audio file and this measures its dynamics — the same ITU-R BS.1770-4 loudness pipeline used for broadcast compliance, plus the DR value that record collectors argue about.

Everything runs in your browser. Nothing is uploaded anywhere. This is the measurement core of pressing-matters, ported from Python. Try the same album on vinyl and streaming and compare.

Integrated loudness
—LUFS
Gated average loudness. Streaming platforms normalise to about −14.
Loudness range
—LU
How much the loudness actually moves. Higher means it breathes.
True peak
—dBFS
Above 0 means inter-sample clipping from limiting.
Crest factor
—dB
Peak-to-RMS. A sine is 3.01 by definition.
DR value
—
What the Dynamic Range Database quotes. Under 7 is heavily compressed.
