Currently building

turntableReal data

A personal music data platform. Four music APIs that fundamentally disagree about what an album is — Discogs thinks in physical pressings, MusicBrainz in release groups, Last.fm in loose strings — resolved into one warehouse. Now running on live Discogs × MusicBrainz data: the real run exposed a limitation the synthetic fixture couldn't (live albums and compilations fooling the matcher), and fixing it with release-type signals lifted precision from 0.48 to 0.83.

real data: precision 0.83 · recall 1.00 · fixture 1.00 · 90% fewer comparisons

pressing-mattersReal data

Do different pressings of the same album actually sound different? A BS.1770 loudness/dynamics implementation, validated against analytically known signals, then run on real Creative-Commons tracks and cross-checked against AcousticBrainz's independent Essentia measurements — they agree at r = 0.77.

9 checks vs theory · real-audio dynamics match Essentia at r = 0.77

birdsong-robustnessIn progress

Published bird-song classifiers are evaluated on clean, curated recordings. The field is wind, traffic, overlapping calls, and cheap microphones. This measures how far they actually fall — a robustness benchmark across controlled degradation axes.

Python · NumPy · SciPy · signal processing

audio-fingerprintReal data

Shazam-style acoustic fingerprinting from scratch — spectrogram peak constellations, hashed and matched by time-offset voting. Now on 48 real Creative-Commons tracks from the Internet Archive: top-1 identification holds to 0 dB SNR and survives MP3 round-trips, with a clean 0% false-accept operating point.

real audio: top-1 1.000 @ 0 dB SNR · 0.98 on 1-s clips · 0% false-accept

Python · NumPy · SciPy · inverted-index retrieval

audio-sslReal data

Self-supervised contrastive pretraining for audio, hand-written backprop in NumPy (gradient-checked against autograd). A ~20× label-efficiency win on synthetic audio — that, run honestly on real ESC-10, did not transfer. Reported straight, with a falsifying control.

synthetic ~20× win · on real audio it didn't hold — reported straight

Python · NumPy · contrastive learning · NT-Xent

cover-song-idReal data

Are two recordings the same song, in different keys and arrangements? Exact matching fails, so — key-invariant chroma + sequence alignment. Run on the real Da-TACOS benchmark, a prediction from the synthetic phase held: local alignment decisively beats DTW on real reordered covers.

real Da-TACOS: MAP 0.396, P@1 0.68 · key invariance triples it

Python · NumPy · chroma · OTI · DTW / local alignment · MIR

era-earReal data

Can a model hear what era a recording is from? Predicting release year from real audio features (via AcousticBrainz) for 72 tracks across seven decades. The loudness war shows up directly — and two dynamics features predict era as well as all twenty-six.

loudness vs year r = +0.53 · year MAE 13.2 yr vs 17.4 baseline

Python · scikit-learn · AcousticBrainz · grouped CV · feature importance

crate-economicsReal data

Forecasting the vinyl resale market — bridging my ARIMA/forecasting work in industry to the record collection. Walk-forward backtesting; Holt-Winters and ARIMA implemented from the maths. Then I pulled live Discogs prices to check the simulator's core assumption — and found it overstates how strongly scarcity drives price (real slope −0.12 vs an assumed −0.55).

Holt-Winters MASE 0.790 · real Discogs data corrects the scarcity assumption

Python · NumPy · time series · MASE · Discogs API
